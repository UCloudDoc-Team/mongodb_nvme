# 计算规格热升级

## 操作场景

为了满足客户在业务高峰期CPU核不足的场景，MongoDB副本集与分片集的部分机型支持提供对计算规格进行热升级的服务。热升级不需要重启实例，不会中断业务。

## 功能限制

当业务需要对计算规格进行升配，选择热升级后，可升级的计算规格将会被罗列出来。

以下表格说明了不同改配方式是否需要重启。

| 计算规格 | 存储空间 | 是否需要重启 |
| -------- | -------- | ------------ |
| 升配     | 不变     | 否           |
| 升配     | 扩容     | 否           |
| 升配     | 缩容     | 是           |
